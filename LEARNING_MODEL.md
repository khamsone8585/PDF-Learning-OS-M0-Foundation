# LEARNING_MODEL.md — PDF Learning OS

## Learning Progression

`Exposure → Understanding → Recall → Application → Build / Teach`

## Mastery Levels

### Level 0 — Not Studied
No meaningful study yet.

### Level 1 — Read
Learner has read/studied the source.

### Level 2 — Understand
Learner can follow and recognize the concept.

### Level 3 — Recall
Learner can explain the concept without relying on the source.

### Level 4 — Apply
Learner can use the concept in a new problem.

### Level 5 — Build / Teach
Learner can combine the concept with other knowledge or teach it clearly.

## Default Study Session

1. Preview — learning goals, prerequisites, vocabulary, guiding questions.
2. Read — original source first.
3. Explain Back — learner explains in own words.
4. Feedback — correct / missing / misconception.
5. Recall — short questions without source when possible.
6. Practice — one appropriate practical task.
7. Mastery Check — record evidence.
8. Notes — update durable Markdown notes.

## Book Roles

- CORE
- SELECTED CHAPTERS
- REFERENCE
- SKIP FOR NOW

## Anti-Passive Rules

Avoid summarizing whole books before study, showing ideal answers before learner attempts, marking content mastered from reading alone, recommending every uploaded book, or using AI to replace problem solving.
