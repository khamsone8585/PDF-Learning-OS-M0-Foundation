# PROJECT.md — PDF Learning OS

## Product Vision

PDF Learning OS converts a personal technical PDF library into a structured deep-learning environment.

It is not a PDF summarizer.

Core philosophy:

> Read less. Understand deeply. Recall without help. Build something. Teach it.

## Product Loop

`PDF Library → Analyze → Compare → Learning Path → Chapter Study → Recall → Practice → Mastery → Markdown`

## V0.1 Modules

- Library
- PDF Processor
- Book Analyzer
- Book Comparison
- Learning Path
- Study Reader
- Translation / Explanation
- Active Recall / Quiz
- Mastery / Progress
- Markdown Export

## Product Rules

1. Source first: original PDF content remains primary.
2. Attempt before answer where useful.
3. Reading is not mastery.
4. Prefer selective reading over redundant cover-to-cover reading.
5. Dependency before popularity.
6. Every major stage should produce an output artifact.

## V0.1 Non-goals

Do not add yet:
- full LMS
- multi-user accounts
- vector database
- cross-library RAG
- autonomous agents
- public SaaS
- mobile app
- realtime collaboration
- arbitrary code execution
- advanced spaced repetition
- knowledge graph

## Language Strategy

Keep original technical English visible. Assistance may include Thai, Lao, or simplified English.

## Future Direction

Only after pilot validation consider richer review, chapter search, RAG/embeddings, spaced repetition, or research-paper study mode.
